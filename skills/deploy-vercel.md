# Деплой на Vercel

## Что это
Vercel — платформа для хостинга Next.js проектов. Бесплатный тариф подходит для портфолио.

## Как задеплоить с нуля

1. Запушить проект на GitHub
2. Зайти на vercel.com → "Add New Project"
3. Выбрать репозиторий из GitHub
4. Vercel сам определит что это Next.js — настройки оставить по умолчанию
5. Нажать Deploy

## Автоматические деплои
После первого деплоя каждый `git push` в ветку `main` автоматически деплоит новую версию.
Каждый push в другую ветку создаёт preview-ссылку для тестирования.

## Полезные команды локально
```bash
npm run dev      # запустить локально на localhost:3000
npm run build    # проверить что сборка не ломается перед пушем
```

## Домен
- Vercel даёт бесплатный поддомен: `project-name.vercel.app`
- Можно подключить свой домен в настройках проекта (Domains → Add)

## Переменные окружения
Если в проекте есть `.env.local` — добавить переменные в Vercel вручную:
Settings → Environment Variables
